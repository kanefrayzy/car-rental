# Bueno Exotics

Website for an exotic car rental in Patchogue, NY 11772. One car today, a 2023 Dodge Charger SRT Hellcat Widebody Jailbreak; a second may follow, so car data is always an array in config, never hardcoded markup.

The name "Bueno Exotics" is final (client, 2026-10-15) and lives in `site.name` in `frontend/config/site.ts`. The mockups still say "South Shore Exotics"; the config wins.

The engine is not final: specs are the Hellcat's (717 hp, 650 lb-ft, 0-60 in 3.6 s, 196 mph). If it turns out to be a Redeye, `CHARGER_TRIM` in `frontend/config/cars.ts` switches every spec.

## Stack

- Monorepo. `/frontend` is the website; `/backend` is the Laravel 13 booking API (see `backend/README.md` and `backend/CLAUDE.md`). `docker-compose.yml` at the root runs both with MySQL and a mail catcher.
- Next.js 16 (App Router, TypeScript, Turbopack, `cacheComponents: true`), React 19. 16.4.2 since 2026-10-23: 16.0.0 to 16.4.0 have critical advisories (RCE in `use cache` functions returning typed arrays, RCE in the image optimizer with SVG, a Server Actions DoS), and the 16.4.0 build stopped with a SecurityFatalError. Check `npm audit --omit=dev` before upgrading or deploying.
- Tailwind CSS v4. Tokens live in `@theme` in `frontend/app/globals.css`. There is no `tailwind.config.*`.
- Fonts via `next/font/google`: Plus Jakarta Sans (headings, `font-display`), DM Sans (body, `font-sans`). The logo is a drawing, not a font.
- Framer Motion for animation. Every animation must respect `prefers-reduced-motion` and cause no layout shift.
- Root `package.json` holds tooling only (sharp, Playwright). App dependencies go in `frontend/package.json`.

Next.js 16 differs from older versions. Before using a Next API, read the matching guide in `frontend/node_modules/next/dist/docs/` (see `frontend/AGENTS.md`).

## Working notes

- Screenshot loop: `npm run dev` (or `$env:PORT='3100'` first for another port), then `node scripts/shoot.mjs <name> --url http://localhost:3100 --selector "#the-car"` and `node scripts/compare.mjs <name> <1440|390> <x> <y> <w> <h>` with the region in mockup pixels.
- The three phone frames in `design/mobile.png` are drawn at different scales (342px, 272px and 328px wide), so a crop from the middle frame looks larger than the others. Type sizes are normalized across frames, not copied per frame.
- The dev server sometimes misses an edit to `globals.css` when several files are saved at once. If a token change does not show up, re-save the file before debugging anything else.
- The header and footer are in the root layout, and `<html>` has `data-scroll-behavior="smooth"`. Both fix "a phone lands at the footer after Book" (user, 2026-10-16). Next scrolls a new page to the top only if the page's top edge is off screen; when each page rendered the sticky header first, that edge always read as "on screen" (or above `scroll-padding-top`), so Next either kept the old scroll position or called `scrollIntoView` on the whole page fragment, whose children then raced the smooth-scroll animation down to the footer. Do not put the header back into pages. Date and time pickers focus with `preventScroll`.
- Never use `backdrop-filter`, `transform` or `filter` on an ancestor of a `position: fixed` element (it becomes the containing block). The header blur is on its own child layer for this reason.
- The copyright year comes from `NEXT_PUBLIC_BUILD_YEAR` in `next.config.ts`. With `cacheComponents`, reading the clock during render breaks static prerendering; client code that needs today's date uses `lib/useToday.ts`.
- Edit files with the editor tools, not PowerShell `Get-Content`/`Set-Content`: Windows PowerShell 5.1 re-encodes UTF-8 files and corrupts non-ASCII characters.
- Button fills and small blue text use `brand-deep`, not `brand`: white on `brand` is 4.0:1 and fails WCAG AA. `muted` is darker than the mockup sample for the same reason.
- Lighthouse (mobile, production build, with the hero photo): 94 / 100 / 100 / 100; the LCP element is the hero image.
